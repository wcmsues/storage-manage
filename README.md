# 动力二组库房管理系统

库房、物品与工具台账、出入库登记工具。纯静态网页，无后端、无数据库、不联网，数据只存在本机浏览器。

- **电脑**：直接双击 `index.html` 使用，不需要安装任何东西。
- **手机**：打开 GitHub Pages 地址，可「添加到主屏幕」当作 App 使用。

## 能做什么

- 库房建档：库房名、库位、管理员、备注。
- 台账：分「物品」与「工具」两类，记 名称、厂家、规格/型号、数量、单位、库房区域、位置（库位）、所属库房、备注；工具另记「保管维护人」；支持搜索与库房/类别/区域筛选。
- 出入库登记：手机现场选物品或工具、填数量、事由与经办人，库存自动加减，出库不会超过库存。
- 出入库明细：记 出入库、日期、类别、名称、厂家、规格/型号、数量、单位、结存、事由、经办人、库房、位置、备注；可按关键字、出入库、库房、日期范围筛选；明细不可改不可删，记错用「冲正」生成反向记录。
- 导出：台账 CSV、明细 CSV（UTF-8，Excel 直接打开不乱码）。
- 分发：导出单个 JSON 共享包发给同事或组长，对方导入后只读查看，顶部显示数据来源与导出时间。

## 三个人怎么用

| 角色 | 怎么进 | 能做什么 |
|---|---|---|
| 管理员（库房管理岗） | 首次进入设 4 位 PIN + 填姓名 | 建账、登记出入库、导出 CSV 与共享包 |
| 同事 | 导入管理员的共享包 | 查某物品或工具有没有、在哪个库房/区域/位置、还剩多少 |
| 专业组组长 | 导入管理员的共享包 | 查看台账与明细，需要时导出 CSV |

PIN 只用于防止同事误改，不是账号系统，也不做加密。

## 数据与隐私

- 全部数据存在浏览器 `localStorage`，刷新不丢，删除浏览器数据会丢，请定期导出共享包备份。
- 运行时零网络请求（Pages 版仅首次加载页面与检查更新联网）。
- 没有后端，所以同事、组长看到的是导入那一刻的快照，不会自动更新；数据变了就重新导出一份共享包。

## 目录

```
index.html              全站唯一入口，CSS/JS 全部内联，电脑分发就是这一个文件
manifest.webmanifest    PWA 清单（仅 http/https 下加载）
sw.js                   离线缓存（仅 http/https 下注册）
assets/                 应用图标（Logo v3：192 / 512 / 180 / 1024 maskable）
```

`AGENT.md`、`TODO.md`、`DESIGN.md` 是开发协作文档，与使用无关。

## 升级

保持文件名与路径不变，用新 `index.html` 覆盖旧文件即可；升级前建议先在设置页导出共享包。
换电脑、换浏览器同样靠共享包迁移数据：`file://` 与 Pages 的本地存储互不相通。

**0.7.0 起字段口径变更**（库房去掉库房号与联系方式、台账分物品/工具、出入库新增事由与库位），数据结构已升到 v3：

- 0.6.x 的本机旧数据不再读取，也不会被删除；首次打开会提示「旧版本机数据已停用」。
- 旧版（v2）共享包无法导入，会提示用新版重新导出。升级后需要按新字段重新建账。
